# Vladyslav Portfolio Motion Identity

## Style Prompt

A proof-first frontend portfolio reel with a dark interface canvas, sharp glass panels, restrained neon accents, and visible evidence labels. The mood is technical, credible, and energetic without becoming a generic cyberpunk template. The video should feel like a production UI audit turning into a confident portfolio tour.

## Colors

- Canvas: #05080F
- Elevated surface: #0A0E1A
- Panel surface: #111827
- Primary accent: #00D4FF
- Secondary accent: #A855F7
- Evidence accent: #22C55E
- Warm signal: #F59E0B
- Text primary: #F8FAFC
- Text secondary: #94A3B8

## Typography

- Sans: Inter, system-ui, sans-serif
- Mono: JetBrains Mono, Fira Code, monospace
- Large type should be compact, direct, and readable.
- Data labels should use mono, uppercase, and tabular numbers.

## Layout Rules

- Full-bleed composition, no floating card as the whole scene.
- Panels can exist as interface objects, but each scene must have one clear hero message.
- Use evidence chips, route steps, and quality checks as visual proof.
- Keep spacing dense but breathable, closer to a polished product dashboard than a landing page.

## Motion Rules

- Entrance motion should be fast, precise, and staggered.
- Use sweep transitions between scenes instead of jump cuts.
- Ambient glow can move subtly, but do not rely on decoration alone.
- Final scene may fade out; earlier scenes must transition while still visibly intact.

## What Not To Do

- No generic stock laptop mockups.
- No random purple gradient-only hero.
- No fake AI-looking charts without meaning.
- No huge empty marketing claims without evidence.
- No unreadable tiny text or overlapping panels.
