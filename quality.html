Checked, not just shipped

This portfolio is a static site, but it is treated like a small product: every change runs through automated checks before it lands, and the generated HTML is verified against its source.

Automated

Smoke checks in CI

A headless Playwright run on every push and pull request asserts no console errors, no horizontal overflow, that images resolve, and that in-page navigation targets exist.

Build integrity

Generated HTML stays in sync

The homepage is assembled from partials. CI fails if the committed index.html drifts from its source, so the deployed page always matches the repository.

Accessibility

Contrast and motion

Text colours meet WCAG AA contrast in both themes, focus is always visible, and animation respects prefers-reduced-motion.

Standing guardrails

  • Keep claims tied to visible, real work — planned projects are labelled as planned.
  • No unfinished tools or browser-exposed credentials.
  • Production security headers and a Content-Security-Policy on supported hosts.
  • Test both themes, desktop, and mobile after layout changes.
