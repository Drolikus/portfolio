Viber: a messaging interface concept

A planned, mobile-first messaging UI. The focus is the parts that are easy to get wrong — conversation list, thread view, presence, and the many states of a message and an input field.

Problem

States are the hard part

Sent, delivered, read, failed, typing, offline — messaging lives or dies on its states. The concept treats them as first-class, not afterthoughts.

Plan

Thread and input first

Build the thread view and the input field with every state, then the conversation list, presence, and transitions between screens.

Scope

One device, done well

Mobile-first, single-column, with careful touch targets and motion — before considering a desktop split view.

Planned build pass

  • Thread view with full message-state set.
  • Input field: typing, sending, error, attachment states.
  • Conversation list with presence and unread counts.
  • Screen transitions tuned for mobile.
